# Contributing

Thanks for your interest in contributing!

## Development setup

1. Install dependencies: `npm install`
2. Start dev servers: `npm run dev` (frontend at http://localhost:5173, API at http://localhost:8787)

## Pull Requests

- Fork and create a feature branch
- Keep changes focused and add tests where sensible
- Run `npm run lint` and ensure no errors
- Update `README.md` if needed

## Commit Messages

- Use clear, descriptive messages
- Reference issues where applicable

## Code of Conduct

Participation is governed by our `CODE_OF_CONDUCT.md`.
